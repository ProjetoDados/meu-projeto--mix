# Meu Projeto Mix

Este é um site desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades

- Layout responsivo
- Importação de dados de uma planilha do Google Sheets
- Publicado automaticamente via Vercel

## Publicação

O projeto está online em: [https://vercel.com/projeto-dados-projects/meu-projeto-mix](meu-projeto-7a1nsz5zd-projeto-dados-projects.vercel.app)

- CSS3
- JavaScript
- Git + GitHub
- Vercel
